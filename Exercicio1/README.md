\# Exercício 1 - Trajetória com Curva Paramétrica



Projeto desenvolvido em \*\*Unity 6\*\* para a disciplina de \*\*Animação Computadorizada\*\*.



O objetivo do projeto é demonstrar diferentes formas de trajetória utilizando pontos de controle.



Foram implementadas duas trajetórias:



\- Interpolação Linear

\- Curva de Bézier Cúbica



O rato percorre a trajetória selecionada utilizando os queijos como pontos de controle.



\## Controles



Durante a execução do projeto:



\- \*\*Tecla 1\*\* - Seleciona e exibe a trajetória Linear.

\- \*\*Tecla 2\*\* - Seleciona e exibe a trajetória Bézier.



Ao trocar de modo, somente a trajetória selecionada será exibida e o rato passará a percorrê-la.



\## Pontos de Controle



A trajetória utiliza quatro pontos de controle:



\- Cheese0

\- Cheese1

\- Cheese2

\- Cheese3



Os pontos podem ser reposicionados através do editor da Unity para modificar o formato das trajetórias.



\## Engine



\- Unity 6

\- Projeto 3D



\## Execução



1\. Abra o projeto utilizando a Unity 6.

2\. Abra a cena `SampleScene`.

3\. Pressione \*\*Play\*\*.

4\. Utilize as teclas \*\*1\*\* e \*\*2\*\* para alternar entre as trajetórias.
